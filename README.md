# Catalyst Threat Intelligence Feed

Catalyst is a curated cyber threat intelligence feed that aggregates and filters external security reporting into a single RSS feed.

## What it does
- Pulls from multiple cyber news and threat intel sources
- Filters for useful security content
- Tags items with simple severity labels
- Publishes a single RSS feed as `feed.xml`
- Updates automatically via GitHub Actions

## Sources
- Krebs on Security
- BleepingComputer
- CISA
- Unit 42
- Securelist
- Risky Biz

## Output
Once GitHub Pages is enabled, the feed will be available at:

`https://catalyst3389.github.io/catalyst-intel-feed/feed.xml`
